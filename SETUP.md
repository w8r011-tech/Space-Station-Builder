# 🚀 Space Station Builder - Setup Guide

## Installation Instructions

### Step 1: Prepare Roblox Studio
1. Open **Roblox Studio**
2. Create a new blank place
3. In the **Explorer** window, create these folders:
   - `ServerScriptService` (already exists)
   - `ReplicatedStorage` (already exists)
   - `StarterPlayer` → `StarterPlayerScripts`

### Step 2: Copy Shared Files

In **ReplicatedStorage**, create these scripts:

1. **Constants.lua** - Copy from `src/shared/Constants.lua`
2. **Utilities.lua** - Copy from `src/shared/Utilities.lua`

### Step 3: Copy Server Scripts

In **ServerScriptService**, create these scripts:

1. **GameManager.lua** - Copy from `src/server/GameManager.lua` (This is your main startup script)
2. **DataManager.lua** - Copy from `src/server/DataManager.lua`
3. **ResourceSystem.lua** - Copy from `src/server/ResourceSystem.lua`
4. **QuestSystem.lua** - Copy from `src/server/QuestSystem.lua`
5. **EconomySystem.lua** - Copy from `src/server/EconomySystem.lua`

### Step 4: Copy Client Scripts

In **StarterPlayer** → **StarterPlayerScripts**, create these scripts:

1. **LocalPlayer.lua** - Copy from `src/client/LocalPlayer.lua`

In **StarterPlayer** → **StarterCharacterScripts**, create a new folder called **UI** with:

1. **MainGui.lua** - Copy from `src/client/UI/MainGui.lua`
2. **ResourceDisplay.lua** - Copy from `src/client/UI/ResourceDisplay.lua`
3. **BuildGui.lua** - Copy from `src/client/UI/BuildGui.lua`
4. **QuestGui.lua** - Copy from `src/client/UI/QuestGui.lua`

### Step 5: Copy Models

In **ServerScriptService**, create these modules:

1. **StationModules.lua** - Copy from `src/models/StationModules.lua`
2. **Planets.lua** - Copy from `src/models/Planets.lua`

### Step 6: Test the Game

1. Click **Run** or press **F5**
2. You should see:
   - ✅ Resource display in top-left
   - ✅ Building menu on the right
   - ✅ Quest tracker at bottom
   - ✅ Main HUD with station name

## 🎮 How to Play

### Resources
- **Oxygen**: Generated by Life Support buildings
- **Energy**: Generated by Power Plants
- **Food**: Generated by Farms
- **Materials**: Gathered from planets and mining

### Buildings to Build
1. **Life Support** - Generates Oxygen
2. **Power Plant** - Generates Energy
3. **Farm** - Generates Food
4. **Storage** - Increases storage capacity
5. **Research Lab** - Unlock new technologies
6. **Mining Facility** - Generates Materials

### Quests
- Complete quests for experience and resources
- Progress through different difficulty levels
- Unlock new building types

### Exploration
- Visit planets to gather rare resources
- Mercury → Venus → Mars → Jupiter → Saturn
- Higher difficulty = better rewards

### Economy
- Buy and sell resources at dynamic prices
- Prices fluctuate based on demand
- Use Materials as currency

## ⚙️ Configuration

To customize the game, edit `Constants.lua` in `ReplicatedStorage`:

```lua
-- Adjust starting resources
Constants.STARTING_RESOURCES = {
    [Constants.RESOURCES.OXYGEN] = 100,
    -- ... etc
}

-- Adjust building costs
Constants.BUILDING_CONFIG[Constants.BUILDINGS.LIFE_SUPPORT].cost = {Materials = 100}

-- Adjust resource consumption rates
Constants.CONSUMPTION_RATES = {
    [Constants.RESOURCES.OXYGEN] = 0.5,
    -- ... etc
}
```

## 🐛 Troubleshooting

### "Constants not found" error
- Make sure `Constants.lua` is in `ReplicatedStorage`
- Restart the game

### UI not appearing
- Check that UI scripts are in correct location
- Make sure `LocalPlayer.lua` runs first

### Can't build buildings
- Check you have enough resources
- Make sure `GameManager.lua` is running (check console)

### Data not saving
- Roblox DataStore requires proper API setup
- Make sure you're not in local development mode
