# 🚀 Space Station Builder

A complete Roblox game where players build and manage their own space station in the vast universe!

## 🎮 Game Features

### Core Gameplay
- **Build Your Station**: Construct rooms and modules for your space station
- **Resource Management**: Manage Oxygen, Energy, Food, and Materials
- **Technology Upgrades**: Research and unlock new technologies
- **Planet Exploration**: Explore different planets to gather resources
- **Multiplayer**: Play with friends and manage shared stations

### Game Systems
- **Resource Generation**: Auto-producing resources in your station
- **Quest System**: Daily and milestone quests with rewards
- **Economy**: Buy/sell resources at dynamic prices
- **Danger Events**: Space hazards and emergencies to survive
- **Progression**: Level up and unlock new content

## 🛠️ Installation

1. Clone this repository
2. Open Roblox Studio
3. Copy the scripts into their respective locations
4. Configure the game settings in `Constants.lua`
5. Test your game!
